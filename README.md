if you want to help with early development PLEASE make your way to the [Queen's Domain Thread](https://discord.com/channels/731205301247803413/1566938930278957258) in the public Archipelago discord server and shoot a message my way.

## How to Download (if i asked you for help in the discord server):
* Grab one of the zips that starts with 'zDEV' from the Assets section at the bottom of this page: [https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental2](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental2) (lowkey don't know which one but for now it shouldn't matter)
* find your local game files, navigate to `QueensDomain/Binaries/Win64`, and extract the zip into there.  You should see a `ue4ss` subfolder and `dwmapi.dll` in the same place as `QueensDomain-Win64-Shipping.exe`
* grab the code from this repo however you see fit (green code button towards the upper right, just download the zip if you don't know what the other stuff means)
* back in your game files, navigate further into `ue4ss/Mods` and extract the zip or clone the code there.
* if you've done everything correctly, you should see `main.lua` in `[root game folder]/QueensDomain/Binaries/Win64/ue4ss/Mods/QueensDomainArchipelago/scripts/`
